Momentum Turf & Wellness — Play Store PWA Package
===================================================

Files included:
- index.html      Main booking app (with live Firebase REST sync)
- manifest.json   PWA app name, colors, and icon config
- sw.js           Service worker for offline support
- icon-192.png    App icon (192x192)
- icon-512.png    App icon (512x512)

Quick Launch Steps:
1. Create a free Firebase Realtime Database (Test mode) and copy its HTTPS URL.
2. Upload all 5 files above to a free HTTPS host (GitHub Pages, Firebase Hosting, or Netlify).
3. Open your live site, go to the "Owner Sync" tab, and paste your Firebase URL.
4. Paste your live HTTPS URL into https://www.pwabuilder.com/ to generate your Android .aab file for Google Play Console.
